## 系统分层

### 1. 表现层 (Frontend)

**技术栈**: Vue 3.3 + Element Plus + Vite

**核心组件**:
- **Home.vue**: 主页面，整合所有功能
- **TaskForm**: 任务创建表单，支持Git URL和ZIP上传
- **ProgressBar**: 实时进度展示
- **MarkdownPreview**: 论文预览组件
- **TaskHistory**: 历史任务列表

**端口配置**:
- 开发服务器: `7349`
- API代理: `/api` → `http://localhost:7348/api`

### 2. API层 (FastAPI)

**技术栈**: FastAPI 0.104 + Uvicorn

**核心端点**:
| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/tasks` | 创建论文生成任务 |
| GET | `/api/tasks/{task_id}` | 获取任务状态和结果 |
| GET | `/api/tasks/{task_id}/download` | 下载生成的论文 |

**端口配置**: `7348`

### 3. 服务层 (Services)

**TaskService**: 任务管理
- 创建任务
- 查询任务
- 更新任务状态和进度
- 持久化任务结果

**CodeFetcher**: 代码获取
- Git仓库克隆
- ZIP文件解压
- 目录结构验证

**Worker**: 任务执行
- 协调Agent流水线
- 异常处理和重试
- 进度更新

### 4. 数据层 (Data)

**数据库**:
- **SQLite** (默认): 轻量级，开箱即用
- **MySQL** (可选): 生产环境推荐

**Redis**:
- Celery消息代理
- 任务进度缓存
- 实时状态同步

### 5. Agent层 (Intelligence)

详见 [Agent流水线](#agent流水线) 章节。

## 核心模块

### Agent基类 (base.py)

所有Agent继承自 `BaseAgent`，定义统一接口：

```python
class BaseAgent(ABC):
    @abstractmethod
    async def execute(self, context: dict) -> dict:
        """执行Agent任务，返回结果"""
        pass

    def update_progress(self, progress: int, message: str):
        """更新任务进度"""
        pass
```

### 配置管理 (core/config.py)

使用 Pydantic Settings 统一管理配置：

```python
class Settings:
    # 服务配置

    # 数据库配置

    ark_base_url: str
    doubao_model: str

```

## 数据流转

### 任务创建流程

```
用户上传代码
      │
      ▼
FastAPI接收请求
      │
      ▼
CodeFetcher获取代码 (Git clone / ZIP解压)
      │
      ▼
TaskService创建Task记录 (status=pending)
      │
      ▼
Celery任务入队 (process_task)
      │
      ▼
返回task_id给前端
```

## 错误处理

### 错误分类

| 错误类型 | 处理方式 |
|---------|---------|
| 输入验证错误 | 返回400，提示用户修正 |
| Git克隆失败 | 返回400，检查URL或网络 |
| Redis连接失败 | 返回503，提示服务不可用 |
| LLM API调用失败 | 重试3次，失败则标记任务失败 |
| Agent执行异常 | 记录堆栈，标记任务失败 |

### 任务重试机制

Celery任务配置自动重试：
- 最大重试次数: 3次
- 重试延迟: 指数退避 (0.5s → 1s → 2s)
- 重试队列: `tasks`

### 日志记录

所有关键操作记录日志：
- 任务创建/完成/失败
- Agent执行进度
- API调用详情
- 错误堆栈跟踪
